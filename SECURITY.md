# Security policy

Report a vulnerability privately through a
[private advisory](https://github.com/tectonic-os/installer/security/advisories/new),
or to john@johngrant.dev. Do not open a public issue for it.

Every release is before 1.0, so a minor version may break. Only the latest
release receives fixes.

The [threat model](https://tectonic-os.github.io/tectonic/threat-model/) of
`tect` covers this repository too. It names each trust boundary, the control
at each one, and the risks the project accepts.
